# PP_TP1 Julián Santaella 53499

## Como ejecutar

1. Abrir la carpeta `PP_TP1_CORREGIDO` desde IntelliJ IDEA.
2. Seleccionar un JDK instalado (Java 17 o superior).
3. Marcar `src` como Sources Root si IntelliJ no lo reconoce automaticamente.
4. Abrir `src/App.java`.
5. Ejecutar el metodo `main` con el boton ▶.
